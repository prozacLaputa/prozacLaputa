## 我怎么做作品

- **从自己的问题开始。** 不先找一个热门技术，再反过来编需求。
- **本地优先，过程可解释。** 能不上传的数据就留在设备上，AI 结论尽量回到原文和规则。
- **做完再说。** 每个公开项目都包含真实实现、测试或可验证的使用路径，而不只是概念图。
